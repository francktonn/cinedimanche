    Réglages

    Au lancement du timer, le compte du bot écrit le message dans ton chat et l’épingle. Ce compte doit être modérateur de ta chaîne.

    Quand un viewer utilise la récompense de points de chaîne, son pseudo gagne une part en plus sur la roue (il est ajouté d’abord s’il n’y était pas encore). Chaque utilisation compte. Un viewer déjà tiré au sort est ignoré.

    Sans token : la récompense doit demander un message au viewer, elle apparaît alors dans le chat et la page la lit (indique son ID ci-dessus, affiché dès qu’elle est utilisée).
    Avec token : la page écoute directement la chaîne, aucun texte requis. Le token doit être celui du compte de la chaîne.
